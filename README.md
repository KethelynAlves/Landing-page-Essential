# Essential

Landing page responsiva e moderna desenvolvida com HTML5 e CSS3, com foco na apresentação de óleos essenciais naturais.

## 🚀 Tecnologias Utilizadas

* **HTML5**: Estruturação semântica da página.
* **CSS3**: Estilização avançada, utilizando recursos modernos como seletores aninhados, fontes do Google Fonts (*Dela Gothic One* e *Lexend*) e gradientes.

## ⚙️ Funcionalidades do Layout

* **Cabeçalho (Header)**: Logo estilizada, menu de navegação e botão de acesso rápido.
* **Seção Principal (Main)**: Apresentação com título em destaque, texto descritivo e imagem ilustrativa com efeitos de sombra e transição.
* **Rodapé (Footer)**: Links secundários de navegação e créditos de autoria.

## 📁 Estrutura de Arquivos

```text
├── index.html        # Arquivo principal da página
└── styles/
    └── style.css     # Folha de estilos da aplicação
```
🛠️ Como Executar o Projeto
* Faça o clone ou o download deste repositório em sua máquina.

* Abra a pasta do projeto em seu editor de preferência (como o VS Code).

* Abra o arquivo index.html diretamente no seu navegador de internet ou utilize uma extensão como o Live Server para visualizar o site.
